# edgetunnel 项目技术与运维文档

本目录汇集了 **edgetunnel** 的架构演进、并发容灾、访问控制及安全优化相关设计文档。

---

## 📚 文档目录

### 1. [多优选订阅生成器并发容灾与聚合技术指南](./multi_generator_failover.md)
- **解决痛点**：单生成器单点故障、超时宕机阻塞订阅拉取、劣质生成器返回 HTML 伪装页污染客户端配置等问题。
- **架构设计**：
  - 基于 `Promise.allSettled` 的高并发聚合机制；
  - 单生成器 4 秒超时熔断器（`AbortController`）；
  - 全协议清洗与 HTML 伪装页拦截防护；
  - 节点去重合并策略。
- **前端交互**：管理后台动态多生成器卡片列表、无缝双向绑定。
- **推荐清单**：稳定候选生成器可用性实测表。

### 2. [管理后台防缓存机制与登录认证安全指南](./admin_cache_and_auth.md)
- **解决痛点**：浏览器强缓存导致管理后台白屏/跳回 Nginx 伪装页；静态资源更新后前端界面不同步等问题。
- **缓存策略**：精细化 HTTP 标头注入（`no-store, no-cache, must-revalidate`），彻底避免 Disk Cache 污染。
- **认证机制**：
  - 会话保持与 `/login` 自动 302 跳转 `/admin` 的原理解析；
  - 签名算法：`MD5(UA + KEY + ADMIN)`；
  - 防会话劫持与安全退出机制（`/logout`）。
- **运维与排障**：日常管理与常见问题排查建议。
